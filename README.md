Une réinvention ludique de l'invite de commande classique (CLI), habillée aux couleurs de Noël. Ce projet interactif simule un véritable terminal directement dans le navigateur, alliant l'esthétique classique des systèmes d'exploitation à l'esprit des fêtes de fin d'année.

👉 **[Lancer l'Invite de Commande de Noël ici](https://okiportfolio.alwaysdata.net/alice/)**

---

## ✨ Fonctionnalités Principales

* 💻 **Interface CLI Interactive :** Simulation de l'entrée et du traitement des commandes dans un environnement web.
* 🎨 **Design Thématique :** Interface "mode sombre" rehaussée d'éléments visuels et de couleurs inspirés de Noël.
* ⚙️ **Gestion des Commandes :** Interprétation de commandes textuelles via JavaScript pour déclencher des événements ou afficher des réponses personnalisées.
